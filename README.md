## Troubleshooting Methodology

My troubleshooting approach follows a structured process:

1. Identify the issue
2. Gather information
3. Reproduce the problem when possible
4. Isolate the affected component
5. Test possible causes
6. Identify the root cause
7. Apply the appropriate resolution
8. Verify the result
9. Document the solution
10. Escalate when required
